# Skills Tracker Wales – Project Notes

## Purpose
This is a subject-first curriculum visibility and mapping platform for Curriculum for Wales.

It tracks where Literacy, Numeracy, DCF and Cross-cutting Themes are represented across school curriculum planning.

It is not:
- a pupil tracking system
- an assessment system
- a staff performance system
- a behaviour system

## Core Design Principles
- Subject-first, not AoLE-first
- AoLE is optional metadata only
- Low maintenance for staff
- Dropdown-heavy
- No pupil data
- No assessment data
- No judgemental language
- Curriculum visibility and collaboration focus

## Current Core Features
- Whole-school dashboard
- Literacy dashboard
- Numeracy dashboard
- DCF dashboard
- Cross-cutting themes dashboard
- Subject overview
- Subject dashboard
- Curriculum explorer
- Framework browser
- Add mapping entry page
- Admin setup
- School branding
- Framework colour themes
- Practice data tools
- Multi-school-ready structure
- Progression step support

## Optional AoLE Metadata
AoLE should not drive the system structure. It should only appear as optional metadata attached to subjects.

Default AoLE options:
- Expressive Arts
- Health and Well-being
- Humanities
- Languages, Literacy and Communication
- Mathematics and Numeracy
- Science and Technology

## Multi-school Direction
The system should be designed so that each school can eventually have:
- own subdomain
- own branding
- own subjects
- own framework wording
- own users
- own curriculum mappings

Every school-owned data type should eventually include schoolId.

## Progression Steps
Literacy, Numeracy and DCF should support progression steps.

Keep this light-touch:
- Step 3
- Step 4
- Step 5
- Bridging Step 3–4
- Bridging Step 4–5
- Not specified

Progression steps are only a curriculum reference, not pupil assessment.

## Wording Rules
Use:
- curriculum visibility
- mapped opportunities
- represented in planning
- curriculum connections
- review suggested
- progression reference

Avoid:
- weak
- poor
- failing
- compliance score
- staff judgement
- staff ranking
- underperforming
